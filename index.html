01 / One continuous workflow

Render it.
Understand it.
Make it physical.

The core path stays client-side. Web Workers handle the expensive graph and meshing stages while WebGPU handles sorting, rasterization, contribution tracking, picking, and readback.

01

Decode & render

Load six Gaussian formats through vendored GaussForge, preserve float covariance and SH, then render paper-style EWA ellipses with a GPU counting sort.

02

Segment & understand

Build kNN superpoints, lift 2D masks into Gaussian labels with α·T contributions, name instances, and search them with optional CLIP embeddings.

03

Edit & deliver

Select, transform, duplicate, hide, merge, and rename objects with a replayable operation log. Export Gaussian formats, a coloured GLB, or a checked 3MF in millimetres.

02 / F0–F6 architecture

A traceable object pipeline.

Every stage has a concrete browser module, deterministic test fixtures, exportable artifacts, and deployment gates.

  1. Decode into 12-float Gaussians plus SH coefficients.
  2. Rasterize color, depth, normal, ID, and contribution buffers.
  3. Group Gaussians into graph-based superpoints.
  4. Lift masks with reciprocal superpoint and direct-Gaussian overlap evidence.
  5. Name and edit with undoable, replayable operations.
  6. Export or mesh as Gaussian data, GLB, or topology-gated 3MF.

03 / Fabrication path

Splat.
Mesh.
Print.

The browser now implements the path from a Gaussian instance—or the complete visible scene—to a repaired, millimetre-scale 3MF. It blocks files that fail its topology gate; slicer and physical-process validation remain external.

01 / Isolate

Gaussian object

Select or segment one instance, or choose the complete visible scene. For geometry, prefer a 2DGS/GOF source.

02 / Reconstruct

Depth to surface

Orbit cameras render depth and colour. TSDF fusion feeds fast surface nets for GLB or marching tetrahedra for printing.

03 / Verify

Repair + topology gate

Weld vertices, clean faces, orient winding, fill bounded holes, then reject open or non-manifold output.

04 / Deliver

3MF → slicer

Scale the longest dimension in millimetres, rest the part on z=0, export 3MF, then inspect walls, orient, slice, and print.

05 / Before you launch

Static by design. Local when it matters.

Browser requirements

  • A recent Chrome or Edge release with WebGPU enabled.
  • The included 8 MB compact scene loads automatically.
  • Drop your own trained point_cloud.ply for full SH3 rendering.
  • SAM 2.1 and CLIP may download weights from their public providers.

Optional local sidecar

Grok vision, instance naming, Imagine cards, and saving artifacts require the loopback Python sidecar. It is never deployed to GitHub Pages, and your XAI_API_KEY never reaches this site.
