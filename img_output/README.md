# Imagine 2.0 library

Every Grok Imagine card is saved here (not `/tmp`).

```text
img_output/
  index.jsonl
  YYYYMMDD-HHMMSS-name/
    source.png      # 3DGS crop sent to Imagine
    imagine.jpg     # Imagine 2.0 output
    meta.json
```

Generated by `semantic_sidecar` (`POST /analyze` with cards, or `POST /card`). Image files are gitignored; this README is kept.
